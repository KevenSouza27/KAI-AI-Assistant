# KAI-AI-Assistant
Personal AI Assistant using Python, Ollama and local LLMs.
# KAI - Knowledge & Artificial Intelligence

KAI é um assistente pessoal de IA desenvolvido em Python.

## Funcionalidades

- Memória persistente
- Gerenciamento de tarefas
- Lembretes
- Rotinas
- Integração com LLMs locais
- Pesquisa web
- Arquitetura modular

## Tecnologias

- Python
- Ollama
- Gemma 3
- SQLite
- JSON
