# Visão do Projeto

## O que é o KAI

KAI (Knowledge & Artificial Intelligence) é um assistente pessoal baseado em Inteligência Artificial inspirado em assistentes virtuais avançados como JARVIS.

O projeto foi criado com o objetivo de centralizar organização pessoal, gerenciamento de tarefas, memória persistente e interação com modelos de linguagem locais.

## Objetivos

- Ajudar na organização pessoal e profissional.
- Gerenciar tarefas e lembretes.
- Armazenar informações importantes.
- Automatizar atividades repetitivas.
- Evoluir para um assistente inteligente completo.

## Tecnologias Planejadas

- Python
- Ollama
- LLMs Locais
- SQLite
- APIs externas
